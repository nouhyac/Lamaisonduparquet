## La pub : WhatsApp ou site ?
**Recommandation : WhatsApp directement** (« Click-to-WhatsApp »).
- Le pixel Meta n'est pas installé sur le site : une pub vers le site ne peut pas apprendre qui nous contacte. Une pub WhatsApp, si : Meta optimise sur les **conversations commencées**.
- Les restaurateurs répondent sur WhatsApp, pas sur des formulaires. Une offre à 300 000 DA se vend en conversation.
- La règle « choisir son offre avant WhatsApp » est respectée : la pub ne parle que d'une seule offre, la Plateforme restaurant.
- Le site reste dans la bio et sur les affiches (dzignstudio.store) pour ceux qui veulent voir avant d'écrire.

**Réglages**
- Objectif : **Interactions** › conversion : **Applications de messagerie** › **WhatsApp** (numéro 0549 50 68 57 relié à la page Facebook, obligatoire).
- Message d'accueil pré-rempli : « Bonjour, je veux ma démo gratuite de plateforme pour mon restaurant. »
- Audience : Algérie, 25-55 ans, Advantage+ avec suggestions d'intérêts : restaurant, restauration rapide, pizzeria, propriétaire de petite entreprise, administrateurs de pages Facebook.
- Placements : Advantage+ (Reels, Stories, Fil).
- Budget proposé : **5 $ par jour pendant 7 jours = 35 $** (il reste ≈ 54 $ sur la carte, on garde le reste pour pousser la meilleure pub).
- 3 pubs dans le même ensemble : `pub-plateforme-40s.mp4`, `exemple-client.mp4`, `affiche-2.jpg`. Après 3 jours, on coupe la plus chère.
- Texte principal : Texte B. Titre : « Démo gratuite à votre nom ». Bouton : « Envoyer un message WhatsApp ».

**Quand on passera au site** : après la mise en ligne du nouveau paquet (`site-dzign-vite.zip`, avec la section Plateforme) et l'installation du pixel, on testera une 2e campagne vers https://dzignstudio.store/#plateforme.
